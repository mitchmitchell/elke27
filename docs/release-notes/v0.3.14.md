## What's Changed

No breaking changes. Both additions are opt-in or type-only, and default callers behave as in 0.3.13.

### Public `CommandResult` for arm, disarm and zone bypass (#46)

- New public `CommandResult` (a frozen dataclass exported from `elke27_lib`), so callers no
  longer need private client internals to learn whether the panel status refreshed after a
  write.
- Opt in with `return_result=True` on `async_arm_area`, `async_disarm_area` and
  `async_set_zone_bypass`. The default still returns `None`.
- Fields:
  - `route`: `"area_set_arm_state"` or `"zone_set_status"`.
  - `status_refresh_ok`: `True` when the status refreshed (or the reply confirmed it),
    `False` when the panel accepted the command but the follow-up read failed and the entity
    is marked stale, `None` when no refresh applied.
  - Property `refreshed` is `status_refresh_ok is True`.
- Failures still raise the existing public `Elke27*` exceptions.

### Typed package (#47)

- The wheel ships `py.typed` (PEP 561), so type checkers such as mypy `--strict` use the
  package's inline types.

### Not in this release

- Garage door (barrier) support (#48) moves to 0.3.15.
