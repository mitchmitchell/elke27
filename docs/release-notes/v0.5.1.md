## What's Changed

0.5.1 is a patch release (2026-11-12). No breaking changes and no new public
API.

### Bug Fixes / Hardening

- **Discovery import on async setup (#136, #137).** The `discovery` module now
  imports `discovery_socket_thread` when the package loads, instead of calling
  `importlib.import_module` on the asyncio event loop during
  `async_discover_host`. Home Assistant no longer logs a blocking-call warning
  for that path. `discovery_socket_thread` exports `UDP_IPV4_FAMILY` and
  `UDP_DGRAM` so loop code can call `getaddrinfo` without importing `socket` on
  the event loop.
