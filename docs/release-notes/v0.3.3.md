## What's Changed

### New Features

**Public client identity setter**

Added `Elke27Client.set_client_identity(...)` so integrations can configure the
persisted protocol identity before connecting with stored link keys. This avoids
writing to private client attributes when reconnecting after a previous linking
flow.
