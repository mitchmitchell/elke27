## What's Changed

### Bug Fixes

**Thermostat setpoints are sent as whole degrees**

Versions 0.3.5 through 0.3.7 multiplied thermostat setpoints by 10 before
sending `tstat.set_status` (68 F went out as `680`). The E27 Dealer API takes
plain whole degrees (`"cool_setpoint": 75`), so the panel stored the scaled value
and the Elk app displayed it (e.g. `680`). Setpoints are now rounded half up to
whole degrees, and values outside -40..150 raise `ValueError` so pre-scaled
tenths can no longer reach the panel.

Callers should pass degrees (e.g. `heat_setpoint=68` or `68.0`), not tenths.

**Thermostat status values honor the `prec` mask**

Public `ThermostatState` temperature, setpoints, and humidity are now scaled by
the precision bits (b5-b7) of the panel's `prec` array. Panels reporting
precision 0 (the documented `[9,9,9,0]`) are unchanged; a panel reporting one
decimal place now yields `71.5` instead of `715`. These fields are typed
`int | float | None`.
